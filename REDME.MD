# Управление студенческими отметками
Консольное приложение для работы со студентами, предметами и оценками. Данные сохраняются в файлы.

## Сервисы
- **StudentService**: добавление, получение и поиск по фильтру студентов
- **SubjectService**: добавление и получение списка предметов
- **MarkService**: проставление и получение оценок студентов по предметам

## Конфигурация
- **По умолчанию**: файлы сохраняются в "src/main/resources/"
- **Пользовательский путь**: через переменную окружения `STORE_URL`

## Точка входа и фабрика сервисов
Основная точка входа приложения — класс `Runner`, в котором:
1. Создается `PathConfiguration` для определения директории хранения данных (по переменной окружения `STORE_URL` или значению по умолчанию).
2. Создается один экземпляр `ObjectMapper` для работы с JSON.
3. Создается `ServiceFactory`, в конструктор которой передаются `PathConfiguration` и `ObjectMapper`.
4. Из фабрики получаются три сервиса: StudentService, SubjectService и MarkService.
5. Сервисы передаются в `Menu`, которое осуществляет обработку команд пользователя через консоль.
6. Если переменная окружения `STORE_URL` не задана или пуста, используется путь по умолчанию.
